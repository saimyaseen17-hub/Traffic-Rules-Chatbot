# 🚦 Traffic Rules Chatbot

An AI-powered **Traffic Rules Chatbot** that provides quick and helpful answers to common traffic rules and road safety questions.

The chatbot uses **Natural Language Processing (NLP)** and **Machine Learning** to understand user questions and identify the relevant traffic-rule category.

## ✨ Features

* 🚦 Red Light Rules
* 🪖 Helmet Safety Rules
* 🛑 Seat Belt Rules
* 📱 Mobile Phone While Driving
* 🚗 Speed Limit Information
* 🚘 Overtaking Rules
* 🅿️ Parking Rules
* 🪪 Driving License Information
* 🚶 Pedestrian Safety
* 🚑 Emergency Vehicle Rules
* 💬 Interactive chatbot interface
* 🇵🇰 Easy-to-understand traffic rules and responses

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* NLTK
* Scikit-learn
* TF-IDF Vectorizer
* Logistic Regression
* Streamlit

## 🤖 Machine Learning

The chatbot uses:

**TF-IDF Vectorizer**
Converts user questions into numerical features.

**Logistic Regression**
Classifies the user's question into the appropriate traffic-rule intent.

The model was trained on a custom traffic-rules dataset containing questions related to different road-safety categories.

## 🚀 How to Run

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```
